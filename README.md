# Voice Chat Application

Простое приложение для голосовой связи и чата между друзьями.

## Возможности
- Голосовая связь в реальном времени
- Текстовый чат
- Автоматическое создание сервера (хост)
- Подключение клиента по IP адресу
- Минималистичный интерфейс
- Кнопка отключения микрофона (Mute)

## Требования
- Python 3.8+
- Windows/Linux/MacOS
- Установленные зависимости (см. ниже)

## Установка

### Windows:
1. Установите Python с официального сайта: https://python.org
2. Откройте командную строку (cmd) в папке с приложением
3. Выполните команду:
   ```
   pip install -r requirements.txt
   ```

### Linux (Debian/Ubuntu):
```bash
sudo apt-get update
sudo apt-get install -y portaudio19-dev python3-pyaudio python3-tk
pip install -r requirements.txt
```

### Linux (Fedora/RHEL):
```bash
sudo dnf install -y portaudio-devel python3-pyaudio python3-tkinter
pip install -r requirements.txt
```

### macOS:
```bash
brew install portaudio
pip install -r requirements.txt
```

## Использование

### Как хост (сервер):
1. Запустите `python host.py`
2. Приложение покажет ваш IP адрес (например, 192.168.1.100)
3. Сообщите этот IP другу для подключения
4. Сервер будет работать пока вы не нажмете Ctrl+C

### Как клиент:
1. Запустите `python client.py`
2. В поле "IP сервера" введите IP адрес хоста
3. Нажмите "Подключиться"
4. Готово! Можете общаться голосом и писать сообщения

## Важные моменты

### Проблемы с подключением?
- **Брандмауэр**: Разрешите входящие подключения на порт 5000 в брандмауэре Windows/Linux
- **Сеть**: Убедитесь, что вы и друг в одной сети (одна Wi-Fi сеть или локальная сеть)
- **IP адрес**: Используйте локальный IP (начинается с 192.168.x.x или 10.x.x.x)

### Для подключения через интернет:
Если вы хотите подключаться через интернет (не из одной локальной сети):
1. Вам понадобится "белый" IP адрес от провайдера
2. Настройте проброс портов (Port Forwarding) на роутере:
   - Порт: 5000
   - Протокол: TCP
   - Направлять на IP вашего компьютера (хоста)
3. Сообщите другу ваш внешний IP (можно узнать на сайте 2ip.ru)

## Структура проекта
- `host.py` - серверная часть (запускает хост)
- `client.py` - клиентская часть (GUI с чатом и голосом)
- `requirements.txt` - зависимости Python

## Управление
- **Ctrl+Q** - быстрый выход из клиента
- **Кнопка "Выключить микрофон"** - отключает передачу голоса
- **Enter** - отправить сообщение в чат
