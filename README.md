# 🎤 VoiceChat - Простое приложение для голосовой связи

## ✅ ГОТОВОЕ ПРИЛОЖЕНИЕ

В папке `dist/` находится **готовый исполняемый файл** `VoiceChat`, который можно:
- Просто скопировать другу (файл ~27MB)
- Запустить двойным кликом **без установки Python и библиотек**
- Использовать сразу для общения

## 🚀 Как использовать

### 1. ХОСТ (тот, кто создает сервер):
1. Запустите `VoiceChat`
2. Нажмите **"🖥️ Быть ХОСТОМ (сервер)"**
3. Программа покажет ваш IP адрес
4. Сообщите этот IP другу

### 2. КЛИЕНТ (друг):
1. Запустите `VoiceChat` у себя
2. Нажмите **"🔗 Подключиться к другу"**
3. Введите IP адрес хоста
4. Нажмите "Подключиться"

## 💡 Возможности

- ✅ **Голосовая связь** в реальном времени
- ✅ **Текстовый чат** для сообщений
- ✅ **Кнопка Mute** для отключения микрофона
- ✅ **Простой интерфейс** - разберется любой
- ✅ **Не требует установки** - один файл

## ⚠️ Важно

### Локальная сеть (LAN):
- Если вы в одной сети (один Wi-Fi), просто используйте показанный IP
- Обычно это адреса вида `192.168.x.x` или `10.x.x.x`

### Через интернет:
- Нужен **белый (публичный) IP** адрес
- Требуется **проброс порта 5000** на роутере хоста
- Можно использовать сервисы типа Hamachi, ZeroTier для создания виртуальной сети

## 🔧 Технические детали

- Порт для подключения: **5000**
- Формат аудио: Mono, 44100Hz, 16-bit
- Сжатие: простое прореживание для уменьшения трафика
